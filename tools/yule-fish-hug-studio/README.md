# 余乐玩偶抱鱼动作工作站

本地运行：`python -m http.server 18804 --bind 127.0.0.1`，在本目录执行，然后打开 http://127.0.0.1:18804/ 。

使用真实余乐皮肤及已有鱼贴图，按三张用户参考图提供三个可调抱鱼动作。手臂保留游戏原模型的完整几何、比例和贴图，仅整体绕原肩部挂点旋转，不添加手掌、不拆分手肘或缩放，鱼为透明贴图加浅厚度轮廓的物品模型。支持拖动旋转、侧视、转台、呼吸、手部标记、滑块和 JSON 参数导出。

只用于动作预览；尚未替换游戏模型或安装。three.js 0.160.0 及 OrbitControls 离线存放于 vendor/，许可证随附。人物、鱼与参考图片存放本地，无运行时 CDN。
