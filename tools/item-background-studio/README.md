# 物品背景工作站

直接在现代浏览器中打开 `index.html` 即可离线预览。默认角色已嵌入 HTML，不依赖本机绝对路径、外部网络或本地服务器；`character.png` 为单独保存的角色原始素材。

支持角色大小、透明度、连续右摆归位、人物叠加动态残影、半透明星空面板、星空边框，以及斜向动态文字渐变。按住 Shift 展开七项能力说明，松开收起；右侧也可固定展开。拖动角色调整位置，按住 Shift 拖动介绍面板。可替换透明PNG、暂停/定位时间、导入导出参数JSON及导出当前画面PNG。

本工作站是二维效果预览，参数JSON不直接写入Minecraft配置。正式模组中对应实现位于 `DollTooltip.java`。工作站中的七项文本已同步至1.18.1，包含“代价”定时追偿和权柄没收说明。

素材来源：用户提供的角色参考，经生成工具制作透明正面素材并调整姿势。素材权利说明沿用仓库README。
