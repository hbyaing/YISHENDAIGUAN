# 以神戴冠 1.20.0

Minecraft Java 1.20.1 · Forge 47.4.0+ · Java 17

包含成然玩偶、余乐玩偶与白饭，使用独立创造分类“以神戴冠”。联机客户端与服务器应安装相同版本。

## 成然玩偶

佩戴至头部生效，按 H 打开神性面板，可在按键设置中改键。正常从背包取下解除穿戴能力；异常删除自动防拆，无需输入指令。支持创造模式背包正常取下。

1. 众生啊！吾赐汝直视烈阳之权：服务端无限真实血池、伤害与死亡拦截、常规实体删除防护；维持食物、氧气与安全状态。
2. 神明啊！且来见证吾不屈意志：创造飞行、可开关夜视、最高五倍移动与飞行、二十倍挖掘、增加十六格触及距离、可选范围采掘。自动获得注册为正面的效果，包括以后添加模组的正面效果；保留隐身和鬼魂状态，同时强制显示玩家身体和手部皮肤。取下后释放本模组授予的效果和属性，保留外部更强增益。
3. 不朽啊！随吾踏入真正之永恒：记录六十四格内的爆炸破坏，预览并分批恢复普通地形；排除容器、矿石和记录中的玩家放置。
4. 僭越啊！归还汝所窃取之权柄：攻击者标记、常规回血/护盾/复活压制、四次神罚处决。玩偶佩戴者攻击自身后，会被没收其权柄。被没收的头部玩偶保留原始数据，可在成然佩戴者面板中领取。未来玩偶继承 `WearableDoll` 或加入 `starcrowndoll:dolls` 标签即可自动接入。
5. 万象啊！皆当遵从吾至高律令：十二格球形AI暂停，排除友方与玩家；可开关六十四格规则领域，拦截敌对攻击、常规传送/召唤/回血，移除敌对投射物并驱逐敌人。
6. 群星啊！为吾铺就那无尽归途：最远二百五十六格安全瞬移、八个跨维度锚点、上次传送位置与死亡地点返回；虚空及异常远距位移安全返回。
7. 岁月啊！休想抹去吾珍视之物：六十四格友方致命伤害图腾庇护，无图腾消耗；最低血量回溯。命中后附加底层“代价”标记，记录当次实际生命损失，持续十秒，每秒追偿十次，每次为记录值二十倍。追偿不刷新自身，重新命中替换记录并刷新计时。不依赖药水效果，已验证凋零免疫负面状态时仍可结算。

成然提示面板包含人物正面衬图、连续右摆归位、动态人物叠影、半透明星空背景、星点边框和无描边动态渐变文字。按住 Shift 显示完整说明。

## 余乐玩偶与白饭

余乐头戴启用“七美德·谦逊”：体型半格高，限制高于铁质及未分类装备，单次造成和受到的伤害上限为一点，过滤公共AI寻敌、振动与部分凋零/末影龙定向目标。它保留有限生命，连续伤害仍能正常致死。模组装备可通过 `starcrowndoll:humility_allowed_equipment` 和 `starcrowndoll:humility_forbidden_equipment` 标签适配，禁用优先。

两种玩偶可对空气右键佩戴、对方块右键放置。放置后右键切换循环音乐；关闭音乐或破坏玩偶解除。音乐让十六格内生物定身、抖动并旋转，不限制玩家操作。余乐音乐额外每32游戏刻提供一次虚拟白饭，授予瞬间治疗XXIX；不消耗或替换原装备，不产生额外食物掉落。

## 构建和测试

安装JDK17，在仓库根目录运行：

```powershell
.\gradlew.bat build
```

输出：`build/libs/YiShenDaiGuan-1.20.1-1.18.1.jar`。首次构建需联网下载Gradle与Forge依赖。开发客户端：`.\gradlew.bat runClient`。

```powershell
.\gradlew.bat -Pqa qaJar
.\gradlew.bat -Pqa runGameTestServer
```

QA源码与测试模板位于 `tools/qa`，不包含在正式JAR中。使用生成的一次性测试目录，不要把QA模组装入正式存档。1.18.1已通过22项服务端GameTest，包括凋零完整100次追偿、计时不自刷新、实际伤害采样、新命中刷新、取下取消，以及此前能力回归。`tools/qa/verify-core-hooks.ps1` 核验41组必需底层注入签名。

## 边界

第三方Boss的私有血量、独立护盾、跨UUID复活及原生内存写入不保证通用覆盖。地形修复只回放记录中的爆炸破坏，不是全世界回溯；无法可靠区分安装前已有的普通石材建筑。修复排除容器和记录中的玩家放置，建议先预览。追偿以20TPS为时间基准，只对已加载、存活、非友方目标执行；佩戴者取下、离线或离开同一维度后取消，不补发离线伤害。

## 1.18.2 成然可见性
佩戴期间禁止原版隐身与已识别的隐匿效果、保持标准实体可见，取消第三人称火焰动画及第一人称火焰遮屏。自动增益收紧为原版正面效果（不含隐身），不再自动添加外部模组正面效果。取下后恢复正常可见性与燃烧显示行为。

## 1.18.3 恢复跨模组正面效果
恢复按全局效果注册表自动给予全部模组正面效果，不按命名空间限制。仅排除原版隐身和已识别隐匿效果，保留佩戴期间实体可见性拦截及第一/第三人称火焰隐藏。第三方正面效果自动获取已通过独立测试模组验证。

## 1.18.4 玩家皮肤强制显示
佩戴成然时恢复玩家模型各部位可见性、使用当前玩家皮肤的实体裁切渲染，恢复被取消的标准玩家/生物Pre事件。覆盖世界第三人称与背包预览，仍保留全局注册正面效果自动获取，排除ghost_form/ghostform等鬼魂形态效果。已加载灾变3.31并注入模型隐藏/渲染取消进行实测。

## 1.18.5 仅强制渲染皮肤
不再排除、阻止或清除隐身及鬼魂形态正面状态；全部注册正面效果照常自动授予。客户端仅强制显示佩戴者皮肤，火焰隐藏与负面状态免疫保持原行为。已实测隐身与灾变鬼魂形态同时保留时，背包皮肤仍显示。

## 1.18.6 手部皮肤与音乐优先
佩戴成然时第一人称空手、地图及托举玩偶的手部保持显示，隐身和鬼魂形态状态不变。两款玩偶歌曲增强实际响度并限幅，空间音量设为2，32格听音范围内抢占背景音乐、唱片及路径含music/bgm的模组音乐，不修改音量滑块；离开范围、关音乐、破坏或卸载来源后解除，允许正常音乐机制再次播放。普通战斗、脚步等音效保留。

## 1.19.0 余乐第二美德：宽容
佩戴余乐玩偶后自动启用，Shift查看说明。

- 攻击键和左键破坏失效，直接攻击与可追溯的间接伤害取消；涵盖箭、宠物、TNT及带来源的有害效果等路径。
- 水平48格半径、不限高度的和平领域，不强制加载区块。新生成敌对生物在加入世界时处理，已有生物每秒处理。僵尸还原村民；其他敌对分类生物解除武器、攻击目标及攻击动作并永久友好，非攻击AI保留。
- 自放TNT与液体记录归属并保存；红石即时引燃、后续液体流动和摘下后的情况仍保持无伤。自放TNT也不破坏方块，防止后续环境伤害。
- 攻击命中时取消伤害，自己与活体攻击者获得10秒生命恢复X、伤害吸收X（amplifier9）。包括通常无法获得生命恢复的亡灵攻击者。
- 原谦逊的体型、装备限制与存在感抹除继续生效；普通无关TNT和范围外生物保持正常行为。

完整测试范围见 `docs/tolerance-validation-1.19.0.txt`。

## 七美德·慷慨（1.20.0）

佩戴余乐玩偶后，主背包27格锁定，仅快捷栏9格用于主物品存储；装备栏和副手保留。原有主背包物品先移入快捷栏，装不下的作为赠礼散出，不删除。每累计佩戴1200游戏刻（正常20TPS时一分钟）随机散出1～3个单位，保留头上的来源玩偶。自动散财不触发升值。

主动按Q、Ctrl+Q或在背包内悬停按Q，丢出数量保持不变。未安装ProjectE时使用可扩展的材料升值表，例如圆石→铁锭→金锭→钻石→下界合金锭→下界合金块，也支持其他常见材料。数据包可在`data/<命名空间>/generosity_upgrades/*.json`中扩展`upgrades`物品ID映射。

安装等价交换ProjectE后，改为读取其公开EMC接口，随机转换为更高EMC物品：优先选择当前单件EMC的4倍以内，无可容纳原数量的候选时选择最近的更高档。候选覆盖已注册且具有EMC的原版、ProjectE及其他模组物品。转换保留数量和NBT；没有EMC、没有更高可用目标或接口不可用时保留原件，不凭空赋值。重载数据时清理缓存，普通缓存每10秒刷新，选取时重新校验实际EMC。ProjectE为可选联动，无须强制安装。

由其他玩家或具备原生拾物能力的生物拾取赠礼后，双方获得永久村庄英雄X，所有已注册属性的最终值与有效上限翻倍一次。赠送者离线时记录待领取的永久奖励，重新上线恢复。自捡和没有成功拾取不奖励，重复受赠不叠加翻倍。持久化保存在世界存档中；取下玩偶不撤销已经获得的永久祝福。

服务端与客户端需同时更换同版本JAR。
