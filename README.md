# 以神戴冠 1.18.1

Minecraft Java 1.20.1 · Forge 47.4.0+ · Java 17

包含成然玩偶、余乐玩偶与白饭，使用独立创造分类“以神戴冠”。联机客户端与服务器应安装相同版本。

## 成然玩偶

佩戴至头部生效，按 H 打开神性面板，可在按键设置中改键。正常从背包取下解除穿戴能力；异常删除自动防拆，无需输入指令。支持创造模式背包正常取下。

1. 众生啊！吾赐汝直视烈阳之权：服务端无限真实血池、伤害与死亡拦截、常规实体删除防护；维持食物、氧气与安全状态。
2. 神明啊！且来见证吾不屈意志：创造飞行、可开关夜视、最高五倍移动与飞行、二十倍挖掘、增加十六格触及距离、可选范围采掘。自动获得注册为正面的效果，包括以后添加模组的正面效果；隐身除外。取下后释放本模组授予的效果和属性，保留外部更强增益。
3. 不朽啊！随吾踏入真正之永恒：记录六十四格内的爆炸破坏，预览并分批恢复普通地形；排除容器、矿石和记录中的玩家放置。
4. 僭越啊！归还汝所窃取之权柄：攻击者标记、常规回血/护盾/复活压制、四次神罚处决。玩偶佩戴者攻击自身后，会被没收其权柄。被没收的头部玩偶保留原始数据，可在成然佩戴者面板中领取。未来玩偶继承 `WearableDoll` 或加入 `starcrowndoll:dolls` 标签即可自动接入。
5. 万象啊！皆当遵从吾至高律令：十二格球形AI暂停，排除友方与玩家；可开关六十四格规则领域，拦截敌对攻击、常规传送/召唤/回血，移除敌对投射物并驱逐敌人。
6. 群星啊！为吾铺就那无尽归途：最远二百五十六格安全瞬移、八个跨维度锚点、上次传送位置与死亡地点返回；虚空及异常远距位移安全返回。
7. 岁月啊！休想抹去吾珍视之物：六十四格友方致命伤害图腾庇护，无图腾消耗；最低血量回溯。命中后附加底层“代价”标记，记录当次实际生命损失，持续十秒，每秒追偿十次，每次为记录值二十倍。追偿不刷新自身，重新命中替换记录并刷新计时。不依赖药水效果，已验证凋零免疫负面状态时仍可结算。

成然提示面板包含人物正面衬图、连续右摆归位、动态人物叠影、半透明星空背景、星点边框和无描边动态渐变文字。按住 Shift 显示完整说明。

## 余乐玩偶与白饭

余乐头戴启用“七美德·谦逊”：体型半格高，限制高于铁质及未分类装备，单次造成和受到的伤害上限为一点，过滤公共AI寻敌、振动与部分凋零/末影龙定向目标。它保留有限生命，连续伤害仍能正常致死。模组装备可通过 `starcrowndoll:humility_allowed_equipment` 和 `starcrowndoll:humility_forbidden_equipment` 标签适配，禁用优先。

两种玩偶可对空气右键佩戴、对方块右键放置。放置后右键切换循环音乐；关闭音乐或破坏玩偶解除。音乐让十六格内生物定身、抖动并旋转，不限制玩家操作。余乐音乐额外每32游戏刻提供一次虚拟白饭，授予瞬间治疗XXIX；不消耗或替换原装备，不产生额外食物掉落。

## 构建和测试

安装JDK17，在仓库根目录运行：

```powershell
.\gradlew.bat build
```

输出：`build/libs/YiShenDaiGuan-1.20.1-1.18.1.jar`。首次构建需联网下载Gradle与Forge依赖。开发客户端：`.\gradlew.bat runClient`。

```powershell
.\gradlew.bat -Pqa qaJar
.\gradlew.bat -Pqa runGameTestServer
```

QA源码与测试模板位于 `tools/qa`，不包含在正式JAR中。使用生成的一次性测试目录，不要把QA模组装入正式存档。1.18.1已通过22项服务端GameTest，包括凋零完整100次追偿、计时不自刷新、实际伤害采样、新命中刷新、取下取消，以及此前能力回归。`tools/qa/verify-core-hooks.ps1` 核验41组必需底层注入签名。

## 边界

第三方Boss的私有血量、独立护盾、跨UUID复活及原生内存写入不保证通用覆盖。地形修复只回放记录中的爆炸破坏，不是全世界回溯；无法可靠区分安装前已有的普通石材建筑。修复排除容器和记录中的玩家放置，建议先预览。追偿以20TPS为时间基准，只对已加载、存活、非友方目标执行；佩戴者取下、离线或离开同一维度后取消，不补发离线伤害。
