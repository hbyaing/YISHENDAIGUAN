# 1.20.16 玩偶性能优化

## 服务器热路径

- 节制：物品归属使用弱引用位置缓存，命中时仍校验当前槽位和佩戴状态；转移、游标操作与取下即时失效。原生堆叠上限不超过16的物品直接跳过归属扫描；每玩家每tick只执行一次维护。
- 勤勉：自身急迫/速度效果在剩余6tick时续期；惩罚凋零在剩余20tick时续期，避免每tick重复发布药水更新。停止活动仍立即回收自身效果并恢复原有效果。没有放置事件时不复制空队列。
- 音乐：范围扫描从START/END两次合并为每tick一次，重叠音源去重；源列表只在增删时重建，播放、停止和拆除立即失效。生物自身的逐tick控制保持。
- 贞洁：预计算12格圆盘441个偏移，复用扫描坐标，只有实际冻结方块才生成独立坐标；保持每tick扫描、原半径及保护事件。
- 裁决：无标记实体直接返回，移除临时空NBT与查找玩家的Stream分配。

## 客户端介绍页

保留人物、摆动、双动作、透明度、背景和流动配色。换行布局按玩偶、名称、宽度、语言与展开状态缓存；缓存有界，资源重载清理。缓存字形及字宽，正文由逐字绘制改为按行提交，简略说明的斜向渐变保留逐行裁切但每行整段提交。边框和星点批量绘制，避免每像素单独结束绘制批次。

- Forge47.4.26独立生产客户端：两玩偶简略/展开显示、Shift固定/关闭、滚轮分页、连续动画通过。

|---|---:|---:|
