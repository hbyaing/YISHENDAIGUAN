# 余乐玩偶：节制（1.20.6）

戴在头部自动生效，Shift 展开说明中新增第五项“节制”。

- 食物以营养值比较：高于原版面包的 5 点恢复值不能开始进食，直接调用玩家进食入口也会拒绝。
- 同种方块按玩家、维度、区块累计最多成功采掘 10 个。只有实际成功破坏才计数，取消的破坏不计数；数据保存到玩家 Forge 持久化数据，死亡克隆保留，摘戴不重置。
- 原“宽容”的禁止挖掘改为此限额，实体攻击仍禁止；客户端允许对方块使用攻击键。
- 物品栏和鼠标持物每堆最多 16，原本不能堆叠的装备仍为 1。已有超量物品拆分到可用快捷栏；满栏时按慷慨原规则散落，无法散落则托管，不删除。容器外部和掉落物不改变堆叠上限。
- 饱食度 20、饱和度 20、疲劳度 0，保留原版自然回血机制。
- 双手及穿戴装备的标准耐久消耗入口被拦截，直接增加损伤也被拦截，每 tick 清理装备已有耐久损伤。不写永久 Unbreakable 标记，摘下后恢复正常耐久规则。
- 弓没有箭也能发射；实际箭矢不消耗，免费箭只能由创造玩家回收。弩不属于本项承诺。
- 末影珍珠、地面/滑翔烟花、成功放置方块的原版消耗调用不减物品。冷却、统计、生成实体与放置事件保持正常。丢弃、合成和转移不享受零消耗。
- 摘下即解除食物、耐久、堆叠、饱食和消耗限制；已有方块变化及累计计数保留。

## 验证

构建成功。34 项 Forge GameTest 全部通过，包括原有 29 项，以及食物/耐久/摘戴、堆叠数量守恒、实际采掘十次与第十一次、无箭射弓/不可回收/珍珠、方块/地面烟花/滑翔烟花五项。67 组正式版方法描述符检查通过。测试模组不包含在正式 JAR 中。

第三方自定义工具若绕开原版耐久 API 或自行实现消耗，需要另行适配；未宣称覆盖任意外部直接修改 NBT 的实现。
