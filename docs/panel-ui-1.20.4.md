# 成然星空面板 1.20.4

按当前浏览器工作台参数接入：面板不透明度 25%，星空亮度 150%，角色透明度 80%，角色大小 1.12 倍，连续右摆速度 1 倍，残影强度 30%，边框辉光 36，文字流速 2 倍。保持人物残影、动态渐变与背景角色开启，紫色主题。

背景和面板内部均绘制动态星空、缓慢漂移星云，边缘使用五角星与辉光。“不论凡人或不朽，都将承认你的神性”使用连续 RGB 霓虹渐变。图像复用现有物品背景角色贴图，不加载浏览器、不新增运行依赖。游戏像素字体与浏览器字体不同，布局根据游戏 GUI 比例自适应。

保留领域、移动速度、夜视、采掘、锚点、修复、庇护、旧伤重现、玩偶领取和药水过滤。移动速度下新增 3×3×3 / 5×5×5 / 7×7×7 / 9×9×9 采掘范围，默认 3×3×3，以目标方块为中心。沿用原采掘开关与原版破坏判定；跳过容器、不可破坏/硬度超过 50 的方块、未加载区块、世界边界外及高度范围外位置。

范围设置由服务端验证并持久化在玩家 DivineSeven 设置中。网络协议升级至 3，联机双方均需更新此版本。

“外观调试”在游戏内调整八项参数及三个显示开关，关闭面板时保存到客户端 config/starcrowndoll-panel.json。外观不改变服务端技能规则。

验证：25 项 GameTest 通过，包含四档立方体范围边角、边界外保留、容器/基岩保护及设置序列化。另有独立客户端全页面、小 GUI 比例渲染检查和真实客户端/集成服务端网络交互测试。第三方模组不作为本次开发环境 GUI 测试依赖；生产模组目录中其他文件保持原样。
