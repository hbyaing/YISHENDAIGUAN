# 成然玩偶药水过滤 1.20.3

佩戴成然玩偶按 H 打开面板，选择第四页“药水过滤”。列表动态读取药水注册表，支持按名称或注册 ID 搜索、分页，兼容后续新增模组效果。

每个玩家独立保存 potion_disabled 设置，使用已有 DivineSeven 玩家持久化数据及死亡复制流程；退出、重进、摘戴后保留选择。过滤仅在成然玩偶佩戴期间生效。关闭时立即移除效果，并阻止外部重新施加及自动补充；开启后恢复原有规则，不自动赠送负面效果、原版隐身等原先未自动赋予的效果。夜视按钮与过滤页共用同一设置。

网络协议升级为 2，客户端与服务端均需安装 1.20.3。服务器校验佩戴状态及注册效果 ID；界面不直接修改服务端状态。
